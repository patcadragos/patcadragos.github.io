Privacy Policy

Application: Build Until It Works · Last updated: July 1, 2026

This Privacy Policy explains how the Build Until It Works application (the “App”) handles information. The App is a personal tool used by its sole operator to publish their own videos to their own TikTok account through the official TikTok Content Posting API. The App is not offered to, and is not used by, any third-party users.

1. Who we are

Build Until It Works is a personal DIY/engineering content project. The App exists only to upload the operator’s own content to the operator’s own social accounts. There is no user sign-up, no user base, and no service provided to other people.

2. Information the App accesses

  • TikTok OAuth access token. When the operator connects their TikTok account, TikTok issues an OAuth access token (and refresh token). The App uses this token solely to authenticate API requests and to upload videos to the operator’s own account.
  • Content the operator chooses to upload. Video files and their metadata (title, description, caption, privacy setting) that the operator explicitly submits for publishing.
  • Basic API responses. Technical responses returned by TikTok (for example the resulting post ID or an error message) used to confirm whether an upload succeeded.

The App does not access private messages, followers’ data, other users’ content, contacts, precise location, or advertising identifiers.

3. How information is used

Information is used for one purpose only: to publish the operator’s own videos to the operator’s own TikTok account. The App does not use the data for profiling, advertising, analytics about other people, or any automated decision-making.

4. Storage and security

The OAuth token is stored locally on the operator’s own device (for example in a local token file) so the operator does not have to log in for every upload. It is not uploaded to any third-party server controlled by the App. Access to the device is protected by the operator’s own operating-system security.

5. Sharing and selling

We do not sell, rent, trade, or share any data with third parties. The only external party that receives data is TikTok itself, and only as necessary to perform the uploads the operator requests, in accordance with TikTok’s Privacy Policy.

6. Data retention

Tokens are kept only for as long as they are needed to operate the App and can be deleted at any time by removing the local token file (e.g. token.json). Uploaded videos are thereafter governed by TikTok’s own retention rules.

7. Revoking access

The operator can revoke the App’s access at any time by:

  • Opening TikTok → Settings and privacy → Security & permissions → Manage app permissions, and removing this App; and/or
  • Deleting the locally stored token file on the device.

Once access is revoked, the App can no longer act on the account.

8. Children’s privacy

The App is a personal tool operated by an adult and is not directed to children. It does not knowingly collect any information from children.

9. Changes to this policy

This policy may be updated if the App’s functionality changes. The “Last updated” date at the top will reflect any revision.

10. Contact

Questions about this Privacy Policy can be sent to: builduntilitworks@gmail.com.
